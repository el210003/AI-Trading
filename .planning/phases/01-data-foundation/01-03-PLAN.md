<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MT5 terminal (IPC) → backfill/discovery | Partial downloads and out-of-range responses (-4) are routine; treating them wrong corrupts history |
| backfill → stored Parquet | Overwriting/merging history wrong loses bars or duplicates them — silent evidence corruption |
| history report → Phase 3 consumers | Wrong bounds/gaps silently starve or skew future backtests |
