    atr.py: function `wilders_atr(bars: pd.DataFrame, period: int = 14) -> pd.Series`. True Range = max of (high − low), abs(high − prev_close), abs(low − prev_close) composed via pd.concat(...).max(axis=1) with prev_close = close.shift(1). Docstring documents the seed nuance: pandas seeds with the first TR where Wilder's canonical seed is the SMA of the first n TRs — the difference decays geometrically and is immaterial for the 0.1x tolerance use (A4).     swings.py: function `detect_swings(bars: pd.DataFrame, timeframe: str) -> pd.DataFrame`. Validate timeframe is a key of TIMEFRAME_MINUTES else ValueError naming the invariant; validate required columns (symbol, time_utc, high, low) present, time_utc strictly increasing and unique, high/low finite else ValueError. Swing-high mask: high strictly greater than the highs at shifts +1, +2, −1, −2 (all four comparisons); swing-low mirror with strictly less.     zigzag.py: function `build_zigzag(swings: pd.DataFrame) -> pd.DataFrame`.
