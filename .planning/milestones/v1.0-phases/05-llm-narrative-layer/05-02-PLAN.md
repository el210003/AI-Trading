<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| provider output → pipeline | The LLM's returned JSON is untrusted; the pydantic schema + citation check (D-02/D-05) reject malformed/over-reaching output mechanically before it is persisted. |
| pipeline → artifact | The narrative record crosses to storage; it is written atomically and validated for schema before persist so a partial/corrupt record is impossible. |
| provider fallback | A slow/down endpoint must never block setup emission; the timeout/retry encloses the provider call. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-07 | Spoofing | LLM emits a recomputed level/probability in reasoning/citations | high | mitigate | citation_check applies FORBIDDEN_LEVEL_KEYS (drop) + unknown-key + value-mismatch; any violation → unverified → narrative discarded (D-02/D-05), never persisted. |
| T-05-08 | Repudiation | A setup's provenance (LLM vs ML vs unavailable) is ambiguous | medium | mitigate | narrative_status/reason/score_source/agreement are recorded on every narrative record; the ML-only fallback is a labeled observable state, not silence (research OQ2). |
| T-05-09 | Tampering | Partial/corrupt/duplicate narrative artifact | medium | mitigate | writer uses tmp+os.replace atomic write + invariant column validation (refuse unknown/missing columns), mirroring reports.py/artifact.py. |
| T-05-10 | Denial of Service | Slow/hanging LLM endpoint blocks the whole pipeline | high | mitigate | llm_timeout_ms (transport) + llm_max_retries + try/except fallback emit a complete ML-only setup bounded in wall-clock (AI-07/SC3); proven offline by scripted TimeoutError. |
| T-05-11 | Information Disclosure | LLM reasoning/citations leak into persisted numeric level/probability fields | medium | mitigate | only verdict/confidence/reasoning/citations pass the schema; the writer never persists a level field; reasoning is not parsed for levels. |
</threat_model>
