Scaffold the uv-managed Python 3.12 project and build the data foundation's pure layers: validated config (symbols, timeframes, broker offset, paths, limits), UTC-normalization transforms, and the storage access layer (atomic Parquet bars + SQLite WAL meta store with checkpoints, history bounds, and gap tables).
