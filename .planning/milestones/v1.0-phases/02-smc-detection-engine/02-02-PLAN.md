Purpose: sweep-vs-breakout distinction is the core SMC signal input; a tolerance computed from full-frame statistics (the verified reference-library bug) would leak future data into every historical pool decision and invalidate Phase 3 backtests.

A close back on the original side within the window resolves the pool: state swept, event_type sweep, resolved_at = the reclaiming bar's time_utc. Window expiry with no close-back: state broken, event_type breakout, resolved_at = the second window bar's time_utc. Terminal states are final (one-and-done, D-08): a resolved pool is never re-checked; emit exactly one event per pool with event_id f"{pool_id}-E1".
