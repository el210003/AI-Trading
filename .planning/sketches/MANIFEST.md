# Sketch Manifest

## Design Direction

Bold trading-terminal: rich dark surfaces, neon/gradient accents, glassy
panels, high information density that still signals trust. The dashboard is
the product surface for a signals system — it must look like a professional
desk (TradingView / Binance Pro class) while keeping the evidence trace
readable and honest (P(win) + score source + ML↔LLM agreement up front).
Baseline v1 palette (#0B0F17 / #141A26 / #00C7FF + bull/bear semantics) is a
starting point, not a ceiling.

## Reference Points

- TradingView (dense charcoal, chart-first)
- Binance Pro (neon accents on near-black, pill chips)
